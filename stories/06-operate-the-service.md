# 06 - Operate the service

## Goal

Set up monitoring, backups, and documentation so that the service can be
maintained and recovered over time.

## Steps

1. Set up log access, disk-space monitoring, and alerts for failed deploys or
   unexpected server exits.
2. Schedule and verify backups; periodically test restoring one.
3. Document routine maintenance, update cadence, and recovery steps.

## Acceptance criteria

- Logs are accessible and disk-space monitoring is configured.
- Alerts fire for failed deploys or unexpected server exits.
- Backups are scheduled and verified; at least one restore test has been
  performed.
- Routine maintenance, update cadence, and recovery steps are documented.
